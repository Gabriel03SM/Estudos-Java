# Estudos-Java

Repositório com os códigos, exercícios e projetos desenvolvidos durante meus estudos de Java

### Objetivo

Documentar minha evolução aprendendo Java, desde os fundamentos até conceitos mais avançados como Orientação a Objetos, coleções, tratamento de exceções, etc.

🛠️ Tecnologias
Java (JDK 17+)
Sem framework/build tool por enquanto (compilação direta com javac)
